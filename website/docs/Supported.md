# Environments

The `@open-resource-discovery/metadata-renderer` library is designed to be compatible with React 18+ applications and modern web browsers.

Please raise an [issue](https://github.com/open-resource-discovery/metadata-renderer/issues) if there are any problems with UI libraries or framework integrations.

# Files

The following file formats are supported:

- OpenAPI 3.0 / 3.1 (JSON or YAML)
- OpenAPI 2.0 / Swagger (JSON or YAML)
- CSN interop JSON
- AsyncAPI 2.x / 3.x (JSON or YAML)
- A2A agent cards (JSON)
- MCP server cards (JSON)

If you need support for other file formats, please raise an [issue](https://github.com/open-resource-discovery/metadata-renderer/issues).
